الف) اتصال (دکمه «اتصال این آیفون» میان‌بر را با کلید اجرا می‌کند)

  1. If — Shortcut Input · begins with · Bearer (با یک فاصله بعدش)
  2. داخل If: Save File — Shortcut Input · Ask Where to Save خاموش · Subpath: smsledger/key.txt · Overwrite If File Exists روشن
  3. Get Contents of URL — URL: {{ ingest_url }}?source=connect Method: POST · Headers: Authorization = Shortcut Input
  4. Get Dictionary Value — message از Contents of URL ← Show Result — Dictionary Value ← Stop This Shortcut

ب) پیامک (بعد از End If)

  1. Get File — Show Document Picker خاموش · مسیر: smsledger/key.txt
  2. If — Shortcut Input · has any value
  3. Match Text — الگو: {{ otp_pattern }} در Shortcut Input · Case Sensitive خاموش ← If Matches · has any value ← Stop This Shortcut ← End If
    رمز پویا و کد تأیید هیچ‌وقت از گوشی خارج نمی‌شود.
  4. Text — یک خط خالی، بعد Shortcut Input، خط بعد --- ← Append to Text File — Text · مسیر: smsledger/queue.txt
  5. Get Contents of URL — URL: {{ ingest_url }}?source=iphone POST · Headers: Authorization = File (کار ۱) · Request Body: JSON، یک فیلد Text به اسم sms = Shortcut Input

ج) صف (داخل Otherwise؛ وقتی میان‌بر بدون ورودی اجرا شود)

  1. Get File — Show Document Picker خاموش · smsledger/queue.txt · Error If Not Found خاموش ← If File (همین) · has any value
  2. Get Contents of URL — URL: {{ ingest_url }}?split=1&source=queue POST · Headers: Authorization = File (کلید، کار ۱ بخش ب) · Request Body: File = File (صف)
  3. Get Dictionary Value — status ← If Dictionary Value · has any value ← Text --- ← Save File — Ask Where to Save خاموش · smsledger/queue.txt · Overwrite روشن

جواب خطای سرور هیچ‌وقت status ندارد، پس صف فقط بعد از ارسال موفق خالی می‌شود.

Mac دارید؟ فایل آماده میان‌بر را بگیرید و در Terminal امضا کنید: mkdir -p signed && shortcuts sign --mode anyone --input "{{ shortcut_name }}.shortcut" --output "signed/{{ shortcut_name }}.shortcut" فایل امضاشده را با AirDrop به آیفون بفرستید. (آیفون فقط فایل امضاشده را قبول می‌کند؛ قانون اپل.)

۳. ذخیره بانک در مخاطب‌ها

یک پیامک بانک را باز کنید، روی فرستنده بزنید و Create New Contact را بزنید؛ اسمش را بگذارید مثلاً Blu. برای هر بانک دیگر هم همین کار را بکنید. اتوماسیون آیفون فرستنده را فقط از مخاطب‌ها انتخاب می‌کند.

بانک‌های پشتیبانی‌شده: بلو، سامان، خاورمیانه، پاسارگاد، ملی. پیامک بانک‌های دیگر هم ذخیره می‌شود و بعد از اضافه شدن الگوی آن بانک، خودکار خوانده می‌شود.

۴. اتوماسیون پیامک

فقط یک اتوماسیون، یک بار. به آیفون می‌گوید «هر پیامکی از بانک آمد، میان‌بر را اجرا کن». اپل اجازه نمی‌دهد هیچ برنامه‌ای این را خودکار بسازد؛ حدود یک دقیقه کار دستی است. بعد از ساختن، پاکش نکنید.
