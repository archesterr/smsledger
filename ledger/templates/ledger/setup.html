۲. مخاطب بانک

یک پیامک بانک را باز کنید، روی فرستنده بزنید و Create New Contact را بزنید؛ اسمش را بگذارید مثلاً Blu. برای هر بانک دیگر هم همین کار را بکنید. اتوماسیون آیفون فقط با مخاطب کار می‌کند.

بانک‌های پشتیبانی‌شده: بلو، سامان، خاورمیانه، پاسارگاد، ملی. پیامک بانک‌های دیگر هم ذخیره می‌شود و بعد از اضافه شدن الگوی آن بانک، خودکار خوانده می‌شود.

۴. اتوماسیون (برای هر پیامک)

  1. Shortcuts ← زبانه Automation ← + ← Message.
  2. Sender: مخاطب بانک (می‌شود چند بانک را با هم انتخاب کرد) · Message Contains: کلمه موجودی حساب در پیامک آن بانک:
    • بلو: موجودی
    • سامان، خاورمیانه، پاسارگاد، ملی: مانده
    برای هر کلمه یک اتوماسیون جدا بسازید (یکی برای بلو، یکی برای بقیه). این کلمه پیامک‌های تبلیغاتی بانک را کنار می‌گذارد.
  3. iOS ۱۷ و بالاتر: Run Immediately را انتخاب و Notify When Run را خاموش کنید.
  4. New Blank Automation ← کار Run Shortcut ← «SMS to Ledger» ← روی فلش بزنید و Input را Shortcut Input بگذارید.
  5. آزمایش: در Shortcuts میان‌بر «SMS to Ledger» را یک بار دستی اجرا کنید، بعد این صفحه را تازه کنید.

۵. ارسال شبانه صف (پشتیبان)

اگر موقع رسیدن پیامک اینترنت نبود، این میان‌بر هر شب صف را می‌فرستد و بعد پاکش می‌کند. میان‌بر جدید به اسم Sync SMS Queue:

  1. Get File — از پوشه Shortcuts، مسیر smsledger/queue.txt · Error If Not Found خاموش.
  2. If — File · has any value:
    • Get Contents of URL — URL: {{ ingest_url }}?split=1&source=queue Method: POST · همان هدر Authorization · Request Body: File ← File
    • Get Dictionary Value — کلید status از Contents of URL
    • If — Dictionary Value · has any value ← Delete Files ← File (Confirm Before Deleting خاموش) ← End If
  3. End If. بعد در Automation: Time of Day ساعت ۳:۰۰ هر روز ← Run Immediately ← Run Shortcut «Sync SMS Queue».

فقط وقتی سرور جواب درست بدهد صف پاک می‌شود؛ خطا یا نبود اینترنت صف را نگه می‌دارد. ارسال تکراری هم مشکلی ندارد.
