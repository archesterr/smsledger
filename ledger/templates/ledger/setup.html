۲. مخاطب بانک

یک پیامک بانک را باز کنید، روی فرستنده بزنید و Create New Contact را بزنید؛ اسمش را بگذارید مثلاً Blu. برای هر بانک دیگر هم همین کار را بکنید. اتوماسیون آیفون فقط با مخاطب کار می‌کند.

بانک‌های پشتیبانی‌شده: بلو، سامان، خاورمیانه، پاسارگاد، ملی. پیامک بانک‌های دیگر هم ذخیره می‌شود و بعد از اضافه شدن الگوی آن بانک، خودکار خوانده می‌شود.

برنامه Shortcuts ← زبانه Shortcuts ← دکمه + ← اسم: SMS to Ledger. این کارها را به ترتیب اضافه کنید:

تنظیماتی مثل Method، Headers، Case Sensitive و Make New Line زیر Show More یا فلش (›) کنار هر کار پنهان است؛ اول آن را بزنید.

⚠️
Shortcut Input را تایپ نکنید. روی جای خالی بزنید، و از نوار بالای کیبورد Shortcut Input را انتخاب کنید تا به شکل یک دکمه آبی دربیاید. اگر تایپش کنید، به جای پیامک خود کلمه «Shortcut Input» فرستاده می‌شود.
  1. Match Text — متن: Shortcut Input · الگو (Pattern): رمز(?!\s*ارز)|یک.?بار|کد.?(تایید|تأیید|ورود|فعال|پویا)|OTP
    Case Sensitive را خاموش کنید. این مرحله نمی‌گذارد رمز پویا و کد تأیید از گوشی خارج شود.
  2. If — Matches · has any value ← داخلش: Stop This Shortcut ← End If.
  3. Text — اول Shortcut Input، خط بعد فقط ---
  4. Append to Text File — متن: Text · مسیر فایل: smsledger/queue.txt · Make New Line روشن.
    اگر اینترنت نباشد، پیامک اینجا می‌ماند و شبانه ارسال می‌شود.
  5. Get Contents of URL
    • URL: {{ ingest_url }}?source=iphone
    • Method: POST
    • Headers: کلید Authorization · مقدار: کلید دستگاه (با Bearer اولش)
    • Request Body: JSON · یک فیلد Text به اسم sms با مقدار Shortcut Input

۴. اتوماسیون (برای هر پیامک)

دو اتوماسیون لازم است، هر کدام با یک کلمه (کلمه موجودی حساب در پیامک آن بانک؛ پیامک‌های تبلیغاتی بانک را کنار می‌گذارد):

  • بلو: «موجودی»
  • سامان، خاورمیانه، پاسارگاد، ملی (همه با هم در یک اتوماسیون): «مانده»

مراحل در iOS ۱۶ و ۱۷ فرق دارد. نسخه گوشی: Settings ← General ← About ← iOS Version. {% if ios %}این صفحه روی گوشی با iOS {{ ios|fa }} باز شده؛ راهنمای همان نسخه باز است.{% endif %}

= 17 %} open{% endif %}>iOS ۱۷ و بالاتر
  1. Shortcuts ← زبانه Automation ← + ← Message.
  2. Sender: مخاطب بانک (چند بانک را می‌شود با هم انتخاب کرد) · Message Contains: کلمه بالا.
  3. Run Immediately را انتخاب و Notify When Run را خاموش کنید ← Next.
  4. New Blank Automation ← کار Run Shortcut ← «SMS to Ledger» ← روی فلش بزنید و Input را Shortcut Input بگذارید ← Done.

نتیجه: با هر پیامک، کاملاً خودکار و بی‌صدا.

iOS ۱۶ (و ۱۴، ۱۵)

در iOS ۱۶ دکمه «New Blank Automation» و گزینه «Run Immediately» وجود ندارد؛ این مراحل را بروید:

  1. Shortcuts ← زبانه Automation (پایین صفحه) ← Create Personal Automation.
    اگر قبلاً اتوماسیون ساخته‌اید، اول دکمه + بالای صفحه.
  2. لیست را پایین بروید ← Message.
  3. Message Contains ← Choose ← کلمه بالا را بنویسید ← Done.
    Sender ← Choose ← مخاطب بانک‌ها را انتخاب کنید ← Done.
    بالا سمت راست: Next.
  4. Add Action ← در جستجو بنویسید Run Shortcut ← انتخابش کنید.
  5. در کار Run Shortcut روی کلمه کم‌رنگ Shortcut بزنید ← «SMS to Ledger». بعد روی فلش (›) کنار کار بزنید تا Input دیده شود ← Input ← Shortcut Input.
  6. بالا سمت راست: Next ← اگر Ask Before Running هست، خاموشش کنید و در پیام بعد Don't Ask را بزنید ← Done.
  7. برای کلمه دوم («مانده») همین مراحل را دوباره بروید.
👆
در iOS ۱۶ با هر پیامک بانک یک اعلان از Shortcuts می‌آید؛ لمسش کنید تا اجرا شود. این محدودیت خود اپل برای اتوماسیون پیامک است (در iOS ۱۷ برداشته شد) و هیچ برنامه‌ای نمی‌تواند دورش بزند.

اسم دکمه‌ها ممکن است بین نسخه‌های فرعی کمی فرق کند؛ اگر چیزی را پیدا نکردید، دنبال همان کلمه در صفحه بگردید.

آزمایش با یک پیامک واقعی: جزئیات میان‌بر (ⓘ) ← Show in Share Sheet را روشن کنید؛ بالای میان‌بر خط If there's no input ظاهر می‌شود ← آن را Get Clipboard بگذارید. حالا یک پیامک بانک را کپی کنید (نگه دارید ← Copy) و میان‌بر را دستی اجرا کنید، بعد صفحه خانه را ببینید. با همین روش پیامک‌های قدیمی را هم می‌شود یکی‌یکی فرستاد.

اگر لمسی جا بماند، صفحه «خانه» جای خالی را از روی موجودی پیدا می‌کند و خبر می‌دهد؛ پیامک را از وارد کردن پیامک اضافه کنید.

۵. ارسال شبانه صف (پشتیبان)

اگر موقع رسیدن پیامک اینترنت نبود، این میان‌بر هر شب صف را می‌فرستد و بعد پاکش می‌کند. میان‌بر جدید به اسم Sync SMS Queue:

  1. Get File — از پوشه Shortcuts، مسیر smsledger/queue.txt · Error If Not Found خاموش.
  2. If — File · has any value:
    • Get Contents of URL — URL: {{ ingest_url }}?split=1&source=queue Method: POST · همان هدر Authorization · Request Body: File ← File
    • Get Dictionary Value — کلید status از Contents of URL
    • If — Dictionary Value · has any value ← Delete Files ← File (Confirm Before Deleting خاموش) ← End If
  3. End If.

اتوماسیون شبانه:

  • iOS ۱۷+: Automation ← + ← Time of Day ← ساعت ۳:۰۰، Daily ← Run Immediately ← Next ← New Blank Automation ← Run Shortcut «Sync SMS Queue».
  • iOS ۱۶: Automation ← Create Personal Automation (یا +) ← Time of Day ← ساعت ۳:۰۰، Daily ← Next ← Add Action ← Run Shortcut «Sync SMS Queue» ← Next ← Ask Before Running خاموش ← Don't Ask ← Done.
    اتوماسیون ساعت‌دار در iOS ۱۶ بدون لمس اجرا می‌شود.

فقط وقتی سرور جواب درست بدهد صف پاک می‌شود؛ خطا یا نبود اینترنت صف را نگه می‌دارد. ارسال تکراری هم مشکلی ندارد.
