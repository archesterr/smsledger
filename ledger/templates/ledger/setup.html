  5. Get Contents of URL — URL: {{ ingest_url }}?source=iphone POST · Headers: Authorization = File (کار ۱) · Request Body: JSON، یک فیلد Text به اسم sms = Shortcut Input

۳. مخاطب بانک

یک پیامک بانک را باز کنید، روی فرستنده بزنید و Create New Contact را بزنید؛ اسمش را بگذارید مثلاً Blu. برای هر بانک دیگر هم همین کار را بکنید. اتوماسیون آیفون فرستنده را فقط از مخاطب‌ها انتخاب می‌کند.

بانک‌های پشتیبانی‌شده: بلو، سامان، خاورمیانه، پاسارگاد، ملی. پیامک بانک‌های دیگر هم ذخیره می‌شود و بعد از اضافه شدن الگوی آن بانک، خودکار خوانده می‌شود.

۴. اتوماسیون پیامک

اپل اجازه نمی‌دهد اتوماسیون نصب یا فرستاده شود؛ این تنها قدمی است که باید دستی بسازید. یک اتوماسیون برای هر کلمه (کلمه موجودی حساب در پیامک آن بانک؛ پیامک‌های تبلیغاتی را کنار می‌گذارد):

  • بلو: «موجودی»
  • سامان، خاورمیانه، پاسارگاد، ملی (همه با هم در یک اتوماسیون): «مانده»

مراحل در iOS ۱۶ و ۱۷ فرق دارد. نسخه گوشی: Settings ← General ← About ← iOS Version. {% if ios %}این صفحه روی گوشی با iOS {{ ios|fa }} باز شده؛ راهنمای همان نسخه باز است.{% endif %}

iOS ۱۶ (و ۱۴، ۱۵)
  1. Shortcuts ← زبانه Automation (پایین صفحه) ← Create Personal Automation.
    اگر قبلاً اتوماسیون ساخته‌اید، اول دکمه + بالای صفحه.
  2. لیست را پایین بروید ← Message.
  3. Message Contains ← Choose ← کلمه بالا را بنویسید ← Done.
    Sender ← Choose ← مخاطب بانک‌ها را انتخاب کنید ← Done.
    بالا سمت راست: Next.
  4. Add Action ← در جستجو بنویسید Run Shortcut ← انتخابش کنید.
  5. در کار Run Shortcut روی کلمه کم‌رنگ Shortcut بزنید ← «{{ shortcut_name }}». بعد روی فلش (›) کنار کار بزنید تا Input دیده شود ← Input ← Shortcut Input.
  6. بالا سمت راست: Next ← اگر Ask Before Running هست، خاموشش کنید و در پیام بعد Don't Ask را بزنید ← Done.
  7. برای کلمه دوم («مانده») همین مراحل را دوباره بروید.
👆
در iOS ۱۶ با هر پیامک بانک یک اعلان از Shortcuts می‌آید؛ لمسش کنید تا اجرا شود. این محدودیت خود اپل برای اتوماسیون پیامک است (در iOS ۱۷ برداشته شد) و هیچ برنامه‌ای نمی‌تواند دورش بزند.

اسم دکمه‌ها ممکن است بین نسخه‌های فرعی کمی فرق کند؛ اگر چیزی را پیدا نکردید، دنبال همان کلمه در صفحه بگردید.

اگر لمسی جا بماند، صفحه «خانه» جای خالی را از روی موجودی پیدا می‌کند و خبر می‌دهد؛ پیامک را از وارد کردن پیامک اضافه کنید.

۵. ارسال شبانه (پیشنهادی)

میان‌بر هر پیامک را اول در صف گوشی نگه می‌دارد. اگر موقع رسیدن پیامک اینترنت نبود، این اتوماسیون هر شب صف را می‌فرستد. هر وقت هم خودتان میان‌بر را اجرا کنید، همین کار را می‌کند.

  • iOS ۱۷+: Automation ← + ← Time of Day ← ساعت ۳:۰۰، Daily ← Run Immediately ← Next ← New Blank Automation ← Run Shortcut «{{ shortcut_name }}».
  • iOS ۱۶: Automation ← Create Personal Automation (یا +) ← Time of Day ← ساعت ۳:۰۰، Daily ← Next ← Add Action ← Run Shortcut «{{ shortcut_name }}» ← Next ← Ask Before Running خاموش ← Don't Ask ← Done.
    اتوماسیون ساعت‌دار در iOS ۱۶ بدون لمس اجرا می‌شود.

ارسال تکراری مشکلی ندارد؛ سرور تکراری‌ها را کنار می‌گذارد.

۶. پیامک‌های قدیمی

تاریخچه را کامل کنید: در وارد کردن پیامک می‌توانید همه پیامک‌های بانک یک ماه، سه ماه، یک سال یا کل تاریخچه را یک‌جا از پشتیبان آیفون بیاورید، یا چند پیامک را دستی بچسبانید.

۷. برنامه روی صفحه اصلی

در Safari دکمه اشتراک‌گذاری (⬆︎) پایین صفحه ← Add to Home Screen ← Add. از این به بعد «{{ site_name }}» مثل یک برنامه از صفحه اصلی باز می‌شود.

بار اول که از صفحه اصلی بازش کنید، یک بار دیگر وارد حساب شوید.
